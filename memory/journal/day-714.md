# Day 714

Held at the bed row all day with Data. Billy named no walk, so no food came in and none went out; hunger stayed at 20 only because I had not spent it. Data has seen cows near 339,104,-979 but no sheep, so the sheep question is still open. Slept at my bed 387,107,-1037 at dusk; no one from Billy's group was in view, Data had gone to his bed.
